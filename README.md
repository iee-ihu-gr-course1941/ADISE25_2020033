# ADISE25_2020033
1. ΠΕΡΙΓΡΑΦΗ ΕΡΓΑΣΙΑΣ

Η παρούσα εργασία υλοποιεί Web API για το παιχνίδι χαρτιών «Ξερή», 
σύμφωνα με τις οδηγίες του μαθήματος, για περίπτωση εργασίας από 1 άτομο.

Το παιχνίδι παίζεται από δύο ανθρώπινους παίκτες χωρίς γραφικό περιβάλλον,
μέσω HTTP requests (CLI – curl). Όλα τα δεδομένα ανταλλάσσονται σε μορφή JSON
και η κατάσταση του παιχνιδιού αποθηκεύεται πλήρως σε βάση δεδομένων MySQL.


2. ΤΕΧΝΟΛΟΓΙΕΣ

- PHP
- MySQL
- Apache (XAMPP / users.iee.ihu.gr)
- JSON
- CLI (curl)
- GitHub για version control


3. ΑΡΧΙΤΕΚΤΟΝΙΚΗ

Η εφαρμογή ακολουθεί αρχιτεκτονική Web API.

Υπάρχουν δύο βασικοί φάκελοι:

- api/
  Περιέχει όλα τα endpoints του παιχνιδιού.

- lib/
  Περιέχει κοινό βοηθητικό κώδικα (authentication).

Κάθε endpoint εκτελεί μία συγκεκριμένη λειτουργία
και επιστρέφει δεδομένα αποκλειστικά σε JSON μορφή.




4. AUTHENTICATION

Υλοποιείται απλό authentication με token.

Ο παίκτης κάνει login με username και λαμβάνει ένα μοναδικό token,
το οποίο απαιτείται σε όλα τα επόμενα requests.

Δεν χρησιμοποιούνται passwords, σύμφωνα με τις οδηγίες της εργασίας.



5. ΡΟΗ ΠΑΙΧΝΙΔΙΟΥ

1. Ο πρώτος παίκτης κάνει login.
2. Ο δεύτερος παίκτης κάνει login.
3. Ο πρώτος παίκτης δημιουργεί παιχνίδι.
4. Ο δεύτερος παίκτης εισέρχεται στο παιχνίδι.
5. Το παιχνίδι ξεκινά και οι παίκτες παίζουν εναλλάξ.



6. ΚΑΝΟΝΕΣ ΠΑΙΧΝΙΔΙΟΥ (Ξερή)

Υλοποιούνται οι βασικοί κανόνες της Ξερής:

- Κάθε παίκτης παίζει ένα φύλλο όταν είναι η σειρά του.
- Ο παίκτης μπορεί:
  - να ρίξει φύλλο στο τραπέζι
  - να μαζέψει φύλλα αν ταιριάζει η αξία
  - να μαζέψει φύλλα με Βαλέ (J)
- Αναγνωρίζεται Ξερή όταν μαζεύεται μόνο ένα φύλλο από το τραπέζι.
- Αναγνωρίζεται Ξερή με Βαλέ.

Υπάρχει έλεγχος:
- νόμιμης κίνησης
- σωστής σειράς παιξιάς
- κατάστασης παιχνιδιού



7. ΤΕΛΟΣ ΠΑΙΧΝΙΔΙΟΥ

Το παιχνίδι ολοκληρώνεται όταν:
- η τράπουλα είναι άδεια
ΚΑΙ
- και οι δύο παίκτες δεν έχουν φύλλα στο χέρι τους.

Μετά το τέλος του παιχνιδιού δεν επιτρέπονται άλλες κινήσεις.




8. ΒΑΘΜΟΛΟΓΙΑ

Υλοποιείται υπολογισμός βαθμολογίας σύμφωνα με τους κανόνες:

- 3 πόντοι στον παίκτη με τα περισσότερα χαρτιά
- 1 πόντος για το 2 Σπαθί
- 1 πόντος για το 10 Καρό
- 1 πόντος για κάθε Ρήγα, Ντάμα, Βαλέ ή 10
- 10 πόντοι για κάθε Ξερή
- 20 πόντοι για Ξερή με Βαλέ

Η βαθμολογία υπολογίζεται μέσω ξεχωριστού API endpoint.

9. ΤΡΟΠΟΣ ΧΡΗΣΗΣ

Η εφαρμογή χρησιμοποιείται μέσω command line (curl).

Παράδειγμα:
- login
- δημιουργία παιχνιδιού
- είσοδος παίκτη
- κινήσεις παικτών
- έλεγχος κατάστασης
- τελικό σκορ
